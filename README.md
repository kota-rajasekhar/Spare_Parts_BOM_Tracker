# Spare Parts & BOM Tracker

Excel tracker that links pharma equipment to spare parts, quantities and costs, so teams can identify parts quickly and plan maintenance spend.

## What it does
- Maps 5 equipment types (reactor, mixing tank, storage vessel, filter, dryer) to 12 spare parts by part code
- Calculates spare-part cost per equipment (total: ₹1,88,800)
- Scales BOM requirements to order quantity (100 reactors = ₹34,00,000 in parts)

## Files
- `Pharma_Equipment_BOM_Project (R).xlsx`: full workbook (download to open)

## Sheets
| Sheet | Purpose |
|---|---|
| Equipment_Summary | Parts, quantity, unit cost and total cost per equipment |
| Bill_of_Material_Report | Required quantity and cost for a bulk order |
